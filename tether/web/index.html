First-time setup

Three things, once.

1

Anthropic API key ✓ saved

tether uses Claude to read papers. Get a key at console.anthropic.com → API Keys.
Stored only on this computer, in tether's .env file (which git ignores, so it never gets committed). It's sent only to Anthropic. This page never sees it again after you save; it shows just the first and last few characters.
2

Your Obsidian vault ✓ set

A vault is just a folder Obsidian treats as one notebook. Links, search and the graph only work inside a vault, so most people keep one vault for everything and use folders inside it. tether puts all its projects in one Tether folder in your vault and doesn't touch your other notes.

Creates an empty vault folder. Afterwards, open it in Obsidian with Open folder as vault.
Obsidian hasn't opened this folder yet. That's fine: in Obsidian choose Open folder as vault and pick it.

Obsidian app ✓ installed

Download Obsidian ↗
4

Zotero optional

Bring papers you've saved in Zotero into tether, and optionally send what tether finds back. You choose how much access tether gets, and can change it any time.
Read access
  • tether reads your library's titles, authors and collections, and the PDFs of papers you pick.
  • It reads a copy of Zotero's database, so it can't change or lock it, even with Zotero open.
  • Only papers you import into a project get read in full and sent to Claude when you build.
Your Zotero data folder (the one with zotero.sqlite). In Zotero: Settings → Advanced → Files and Folders → Show Data Directory.
Write access: tick only what you want
  • tether never deletes anything, and never edits your items' details, your notes or your tags.
  • Writes go through Zotero's official web API and reach your desktop app through normal Zotero sync. tether never writes to Zotero's database file directly.
Needs a zotero.org API key: create one and tick Allow library access, Allow write access and Allow notes access.
5

Models, cost & limits

Which Claude model does which job. Both use prompt caching, so the instructions repeated on every call cost 5–10% of the normal price after the first call. Switching keeps the work already done; only new papers use the new setting.
